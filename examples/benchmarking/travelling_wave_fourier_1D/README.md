# Travelling wave in Fourier space

Waves on a periodic domain x, as a Fourier series in time t:
f(x, t) = sum_k a_k(t) cos(k x) + b_k(t) sin(k x), for k = 1, 2, 3.
Each coefficient obeys a_k''(t) + k^2 a_k(t) = 0. The PINN outputs the 6
coefficients and fits f measured at 8 points around the domain.

Needs matplotlib (for plot.py), as well as pinninit.

Files:

- `run.sh`: run the example with `./run.sh`
- `clean.sh`: remove the files generated by running the example
- `generate_data.py`: generate and save the training, validation and test sets
- `param_travelling_wave_fourier_1D.yml`: the parameter file of the PINN
- `travelling_wave_fourier_1D_equations.py`: the equations
- `train.py`: train and save the PINN
- `plot.py`: load the PINN and plot its output
