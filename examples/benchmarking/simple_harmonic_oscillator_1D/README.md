# Simple harmonic oscillator example

Finds f by fitting data points and the residual of f''(x) + omega^2 f(x) = 0, with omega = 1.

Needs matplotlib (for plot.py), as well as pinninit.

Files:

- `run.sh`: run the example with `./run.sh`
- `clean.sh`: remove the files generated by running the example
- `generate_data.py`: generate and save the training, validation and test sets
- `param_simple_harmonic_oscillator_1D.yml`: the parameter file of the PINN
- `simple_harmonic_oscillator_1D_equations.py`: the equations
- `train.py`: train and save the PINN
- `plot.py`: load the PINN and plot its output
